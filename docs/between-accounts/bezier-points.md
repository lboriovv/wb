# Между счетами: точки Безье для шейка

Плашка смещается только по X. Длительность одного цикла — **460 мс**. Отрицательное смещение означает движение влево. Текущая реализация использует затухающую синусоиду; одной `cubic-bezier` ее три смены направления не воспроизвести. Ниже — приближение из шести последовательных кубических сегментов.

| 460 | 100 | 0 |

## Timing function каждого участка

Формат — `cubic-bezier(x1, y1, x2, y2)`. Точки нормализованы **внутри соответствующего участка между соседними ключевыми положениями**.

| Участок, мс | Контрольные точки |
| --- | --- |
| 0–69.216 | `cubic-bezier(0.3333, 0.5949, 0.6667, 1)` |
| 69.216–153.333 | `cubic-bezier(0.3333, 0, 0.6667, 0.5541)` |
| 153.333–222.549 | `cubic-bezier(0.3333, 0.5949, 0.6667, 1)` |
| 222.549–306.667 | `cubic-bezier(0.3333, 0, 0.6667, 0.5541)` |
| 306.667–375.883 | `cubic-bezier(0.3333, 0.5949, 0.6667, 1)` |
| 375.883–460 | `cubic-bezier(0.3333, 0, 0.6667, 1)` |

Для `CAKeyframeAnimation` используйте времена из второго столбца, деленные на 100, и семь значений смещения X из третьего столбца. Каждому интервалу соответствует одна `CAMediaTimingFunction` из таблицы. Это не одна общая easing-функция на все 460 мс.

## Абсолютные точки кубических кривых

Формат каждой точки — `(время в мс, смещение X в pt)`. Эти данные пригодятся, если движок принимает геометрическую траекторию Безье вместо ключевых значений с easing-функциями.

| ---: | --- | --- | --- | --- |
